# Henry Solutions Website

Official website for **Henry Solutions**, a professional low-voltage systems technician and contractor based in Nairobi, Kenya.

## Services
- **DStv Installation & Maintenance:** Precision satellite dish alignment, Explora & ExtraView configuration, signal troubleshooting.
- **Satellite TV Services:** Free-to-Air (FTA), international satellite reception, multi-switch distribution.
- **CCTV & Surveillance Systems:** High-definition IP & analog cameras, NVR/DVR storage, remote smartphone viewing.
- **Smart Home Integration:** Automated lighting, video doorbells, smart locks, gate automation, and Wi-Fi mesh networks.
- **Equipment Procurement:** Direct distributor sourcing of genuine decoders, pure copper Cat6/coaxial cables, cameras, and energizers.
- **Electric Fence Installation:** Wall-top and free-standing high-tensile fences, energizer units, alarm sirens, earthing rods.
- **Fault Inspection & Diagnostics:** Spectrum analysis, insulation resistance testing, cable continuity, and emergency system triage.

## Operational Coverage
- **Kenya:** Nairobi base with nationwide mobilization across all 47 counties.
- **East Africa:** Cross-border commercial and residential project execution (Uganda, Tanzania, Rwanda).
